# MDRG-MODS Meta Repository

This repository is the special community-health and profile repository for the [MDRG-MODS](https://github.com/MDRG-MODS) organization.

## Contents

- [`profile/README.md`](profile/README.md): Organization overview, mod catalog, installation guides, and mission statement displayed on the [MDRG-MODS organization homepage](https://github.com/MDRG-MODS).
- [`.github/ISSUE_TEMPLATE/request-membership.yml`](.github/ISSUE_TEMPLATE/request-membership.yml): GitHub Issue template for modders and community members to request joining the organization.
- [`.github/ISSUE_TEMPLATE/submit-mod.yml`](.github/ISSUE_TEMPLATE/submit-mod.yml): GitHub Issue template for submitting or updating mods.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): Instructions on how to contribute, manage repos, and handle organization membership.
