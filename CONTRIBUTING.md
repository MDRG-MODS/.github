# Contributing to MDRG-MODS

Thank you for your interest in contributing to the **MDRG-MODS** preservation archive!

---

## 🏛️ How the Organization Works

The **MDRG-MODS** organization acts as a decentralized, open archive for modders and players of *!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)*.

### For Organization Administrators
When a user opens a **[Membership Request]** issue:
1. Navigate to your organization page: [`https://github.com/orgs/MDRG-MODS/people`](https://github.com/orgs/MDRG-MODS/people).
2. Click the green **"Invite member"** button.
3. Type the user's GitHub username and select their role (usually **Member**).
4. (Optional) Assign them to a specific team or give them write access to their own repository.
5. Once invited, close the issue and welcome them to the organization!

---

## 📋 Mod Curation Rules

Every repository added to this organization MUST adhere to the following standards:

1. **Preserve Original Code:**
   - Do NOT rewrite or alter mod logic unless fixing a critical game-breaking bug with a clear changelog and note.
   - Retain original comments, headers, and metadata in Lua and JSON files.

2. **Full Attribution & Credits:**
   - Always credit the original modder in the `README.md`.
   - Include their Discord tag, user ID, or external link whenever available.

3. **Strict Compliance with GitHub Terms of Service:**
   - **Sexually Explicit Content Policy:** GitHub does NOT allow hosting sexually explicit imagery (depicting nudity, genitalia, or sexual acts) or pornographic video/media.
   - Code (Lua), JSON configurations, audio clips, and non-explicit cosmetic texture overlays (clothing meshes, hairstyles, room backgrounds) are allowed.
   - Do not upload explicit NSFW imagery.

4. **Releases & Archives:**
   - Each mod repository should have a GitHub Release matching the mod's version.
   - Attach the clean, unpackaged `.zip` archive to the release for 1-click downloads.

---

## 🚀 Submitting a New Mod

To submit a mod for archiving:
1. Use the [Submit a Mod Issue Template](https://github.com/MDRG-MODS/.github/issues/new?template=submit-mod.yml).
2. Provide details, compatibility testing notes, and author credits.
3. An administrator will review the submission, create a repository, and publish the release.
